# ESP8266 Local Messenger with LED Control

## Description
This project is a local messaging system using ESP8266. 
Users can connect through WiFi and send messages using a web browser.
The system also supports LED control and message storage using EEPROM.

## Features
- WiFi hotspot
- Local messaging
- LED control
- EEPROM storage
- Web interface

## Components Used
- ESP8266 NodeMCU
- LED
- Jumper wires

## Libraries Used
- ESP8266WiFi.h
- ESP8266WebServer.h
- EEPROM.h

## Software Used
- Arduino IDE
- GitHub

## How to Run
1. Install Arduino IDE
2. Install ESP8266 board package
3. Upload code to ESP8266
4. Connect to WiFi:
   SSID: DCN
   Password: 12345678
5. Open browser and visit:
   192.168.4.1

## Working
ESP8266 creates a local web server for messaging and LED control.
